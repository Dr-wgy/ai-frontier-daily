# OAuth 授权配置指南

---

## 1. 概述

本指南详细说明如何配置飞书 OAuth 授权，使应用能够获取用户级权限访问飞书资源。

---

## 2. 前置条件

- [x] 已创建飞书企业自建应用
- [x] 已获取 `app_id` 和 `app_secret`
- [x] 应用已发布上线

---

## 3. 配置步骤

### 3.1 步骤 1：配置重定向 URI（白名单）

**这是授权成功的关键步骤！必须配置正确的回调地址。**

1. 登录 [飞书开放平台](https://open.feishu.cn/)
2. 进入应用 → **安全设置** → **重定向 URI**
3. 点击 **添加重定向 URI**

| 场景 | 推荐配置 | 说明 |
|------|----------|------|
| 开发环境 | `http://127.0.0.1:8080` | 本地调试 |
| 生产环境 | `https://your-domain.com/callback` | 线上回调地址 |

**注意**：
- URI 必须完全匹配，包括协议（http/https）、域名、端口和路径
- 支持配置多个 URI，用于不同环境

### 3.2 步骤 2：配置应用权限

在 **权限管理** 中添加以下权限：

#### 基础权限（必须）

| 权限名称 | 权限标识 | 说明 |
|----------|----------|------|
| 获取用户 access_token | `authen:authen:user_access_token`
